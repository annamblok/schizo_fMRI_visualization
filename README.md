# schizo_fMRI_visualization
Made by Anna Blok

Date completed : 06-12-2025

This is a repository for my home assignment for my programming course. The project looks at function brain activity related to the clinical term 'schizophrenia'. 
The link to the neurosynth MRI data I used is the following: https://neurosynth.org/analyses/terms/schizophrenia/. Using an anatomical MRI image and an fMRI image, both images were put together to show the functional activity in the brain in relation to schizophrenia. 
A histogram is also provided, showing the frequency of voxel intensity of the fMRI image.
